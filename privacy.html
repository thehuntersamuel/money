Money Hub — Privacy Policy

Effective August 21, 2026 · Last updated August 21, 2026

Money Hub is a private, single-user personal finance dashboard operated by its owner, Hunter Riley, for his own use. It is not offered to the public, has no customers, and collects no data from anyone other than the owner. This policy describes how the application handles the owner's own financial data.

What data is collected

  • Account information (institution names, account names, types, and balances)
  • Transaction history, investment holdings, and liability details for the owner's linked accounts
  • An email address and password used solely to sign in to the dashboard

Bank sign-in credentials are entered only within Plaid Link, Plaid's secure widget, and are never seen or stored by Money Hub.

How data is used

Data is used exclusively to display the owner's net worth, cash flow, spending, and debt inside the dashboard. It is never sold, rented, shared, or used for advertising, and there are no third-party recipients beyond the service providers below.

Service providers

  • Plaid — connects to financial institutions and retrieves account data
  • Supabase — hosts the database, authentication, and server functions
  • GitHub Pages — serves this static page and the dashboard's front end (no financial data passes through it)

Security

All traffic is encrypted in transit with TLS. All stored data is encrypted at rest. Plaid access tokens are additionally encrypted at the application layer with AES-256-GCM, using a key held only in the server environment and never exposed to the browser. Database access is restricted by row-level security to the single owner account, and the application uses read-only Plaid products — it cannot move money.

Data retention and deletion

Data is retained only while the owner keeps an institution linked and the dashboard in use. Unlinking an institution removes its connection at Plaid and invalidates its access token; the owner may delete stored account and transaction records at any time, and deleting the project removes all stored data permanently. This policy and the retention practice are reviewed quarterly.

Consent and rights

The owner is the only data subject and consents to this processing by operating the application. Plaid's handling of end-user data is described in Plaid's End User Privacy Policy.
